# Roadmap — what is being built now

This lists work that is **in progress and has been deliberately published**. It
is not the backlog: the feature backlog is private, and an item appears here
only when its owner decides to show it. An item missing from this page is not a
statement that nothing is planned.

When an item ships its row is deleted and its record is in
[`BUILT.md`](BUILT.md). When it stops, the row moves to *Stopped* with a reason.
`tools/check-roadmap.mjs` holds all of this, and [`ROADMAP-PROCESS.md`](ROADMAP-PROCESS.md)
says how to add a row.
