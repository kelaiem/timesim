## 320. The maintaining detent finds no clear seat on the double-barrel build since §334 landing 5a

Filed 2026-11-26 by §351 landing 0, which found it running `tools/probe-experimental-specs.mjs` and
`tools/smoke-experimental-specs.mjs` (neither runs in CI) on `main`.

**What the build does.** On the double barrel's one solved build, `barrels=2&vph=36000&alarm=0` (the Experimental build
group's "Double barrel" option, §351), the maintaining detent's site scan in `main.js` finds no azimuth clear of its
obstacles and falls back: `maintaining detent: no clear azimuth found — using the stem-line offset unchecked`. The
detent's post then stands at the stem-line offset WITHOUT the clearance the scan exists to prove. The build's fingerprint
is unchanged (2504693437 before and after), so the metal did not move; what changed is that the scan's obstacle list now
rules out every azimuth it used to accept.

**Where it came from.** Bisected to `bdc65298` (§334 landing 5a: "the detent's post reads the low corridor"). That
commit made the scan consume `LOW_LINKAGE_OBSTACLES` (standing rule 5), correctly: moving the transfer wheel to the
rocking bar's follower had let the scan swing the post into the reset rod on the default build. On the double-barrel
build the corridor's footprint, with barrel B's drum and band beside it, leaves no azimuth at all. The default build and
every CI spec point still find one; no spec point boots the double barrel at 36,000, which is why no gate saw it.

**Why it matters.** The Experimental build group offers the double barrel on the claim that its build boots silent
(`src/experimental-specs.js`' `cleanAt`); it no longer does, so `probe-experimental-specs.mjs` and the smoke test's
step 3 read red on `main`. An unchecked post is a placement nothing measured: the battery has never swept this build.

**Fix path.** Re-site the detent's post on this build in position space (P3): widen the scan's azimuth range or step,
give it the second ring radius it does not try, or move its seat along the great wheel's crossing, until a clear azimuth
exists with the corridor's footprint counted; then add `barrels=2&vph=36000&alarm=0` to `SPEC_POINTS` so the battery
boots it. Retire this item when `probe-experimental-specs.mjs` passes again.
