## 301. case=tonneau's alarm switch drive fork reads the default arrangement's crank arc

Filed 2026-11-13, out of TODO 300's local battery: the full native battery (`battery-native.mjs --query case=tonneau
--shards 4`) runs 35/36. The failure is `lineSpec`, and main at f12ecaf8 reads it the same way, so it is not TODO 300's.

**What is wrong.** The fork `alarm switch drive as folded` (`src/inspect.js` `LINE_SPEC_FORKS`) overrides the reference's
`straight` row with the sagitta of crank B's arc, read off the metal: §261 2c's fold, where crank B's pin works the
driver's slot on an arc through the line's two ends. Its value is per LINE. `value` (0.083199897954356) is the default
arrangement's (28°, 31.34), and since §343 `byLine` keys another line's value by its `'dirDeg|c'` (the 14,400 row's
`'28|31.33'`). The tonneau with the alarm carries a line `byLine` does not list, so it is judged against the default's
sagitta: measured 0.1375419970808574 against 0.083199897954356 (delta 0.0543, tolerance 1e-6).

**What this does not establish.** Whether the tonneau's arc is the right linkage for its line. A larger sagitta is a
pin farther off the pusher's straight line, which the fork says the drive tolerates on the default's line only.
Reading the number into `byLine` holds the metal to itself. It does not judge it.

**Fix path.**
1. Read the tonneau's line and its sagitta the way §343 read the 14,400 row's (`tools/probe-314-linkage-line.mjs --q
   case=tonneau`), and add its `'dirDeg|c'` key to `byLine` with the value measured off its metal.
2. Check the other alarm form kinds carry no unlisted line: fitted and rect pass today. Run `lineSpec` on `case=cushion`
   and on each declared form point.
3. If the tonneau's sagitta is too large for the drive's straddle (P1: the pin leaves the slot's working face), it is a
   layout finding about the tonneau's arrangement, to be filed against its line, not absorbed into the fork.

**Acceptance.** `lineSpec` passes on `case=tonneau`, and on every alarm form kind, with the fork's `byLine` holding each
line's sagitta measured off its own metal.
