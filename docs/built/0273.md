**The sense audit found a defect in the linker, not in the translation.** The
glossary linker's Latin-script boundary was ASCII `\b`, which HOLDS between an ASCII
letter and a diacritic one: on the Czech page the *throw* link wrapped the first five
letters of *zdvihátka* (a follower) and *zdvihací* (lifting) in six entries, and
*derived* the stem of *odvozeným*. `bound`'s `'latin'` case is now the `'word'` rule
(`(?<![\p{L}\p{N}])…(?![\p{L}\p{M}\p{N}])`), and every locale's count was re-measured
against untouched `main`: French 127 → 117, Turkish 91 → 87, Hungarian 100 → 97 —
links inside *posé-*, *-ı* and *-ban* words that were never the term — and the other
nineteen unchanged, English included. The audit then read every Czech link in context
(a dump that places each anchor by DOM range, because an `indexOf` on the block's text
found the wrong occurrence first): five first uses of *poloha* were the everyday
"position" (an alignment, the watch's position dial-up or hanging, a released state)
and were reworded (*pozice*, *orientace*, *stav*) so the link lands on the jargon
sense; *zdvih* carries the escapement's lift as well as a cam's throw, and the
escapement and free-sprung entries' first uses are the lift — reported here, not
reworded, because Czech says *zdvih* for both and the glossary's sense (how far a
tooth moves its pallet) covers it.

**The Czech vocabulary, coined once.** stanoviště, pásmo, vrstva / pruh, koridor,
odstup (the one margin; *vůle* for a clearance), azimut, mezikruží, tětiva, tečna,
zdvih, obálka, jednotka, osa, poloha / napolohovaný, řádek, brána (a gate; *zpráva* a
report), dolní mez / rozpočet, předání, výjimka, akční skupina, přímka, zalomení (a

odvozený, modelováno / simulováno. The numbered plates are *OBR. n* as the primer has
