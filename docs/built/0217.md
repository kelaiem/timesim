**Colon suffixes.** Finnish attaches a case ending to a token with a colon
(`<code>CLEAR_MARGIN</code>:n`, `270°:n`, `18 000:n`), outside the span, so the
`<code>` gate stays byte-identical. On the primer, whose numbers are parsed by value,
the colon is in no token class, so the parse stops there: planted into the real table,
`18 000:n` read **0 number drift** and the control `18 001:n` failed, naming
`[5,18000] vs [5,18001]`.

**The honesty stem had to be measured, not written.** The first `HONESTY.fi.m` was
`/mallin[nt]/` — the verb *mallintaa* is *mallinn-* and *mallint-*. A translator then
satisfied it with *mallintiedostoja* ("model files"), a compound of the NOUN's genitive,
in the chrome's "no models" (which is the 3D-asset noun, and which the chrome's own
probe deliberately does not read as the honesty word). So the stem is the verb's own two
shapes, `/mallinn|mallinta[amnv]/`: it matches *mallinnettu, mallinnus, mallintaa,
mallintaminen, mallintanut, mallintavat* and refuses *malli, mallin, mallia,
tekoälymalli, mallintiedosto, mallintaulu*. The tagline reads *ei valmiita malleja*.

**The sense audit, and one correction to Czech.** Every Finnish link was read in context.
Three first uses were the wrong sense and were reworded: a gong paragraph's *kaista*
(a frequency band, not a lane: now *taajuuskaista*), the feeler's *vapaa asento* (the
English is "free seat": now *istukka*), and the free-sprung entry's position words.
That entry is about the watch's POSITIONS (dial-up, hanging), which Finnish calls
*asento* like the jargon pose, so the pose link landed on "the energy column gives each
position". English links that entry's pose on "the battery still **poses** it". The
fix is in the tables, not a `SENSE_CLASH` row, which would have removed English's true
link: the position phrases say *orientaatio* and the pose row lists the verb *asennoi*,
so Finnish's link lands on *Patteristo asennoi sen*. Czech, merged the same morning
under §273, carried the identical wrong link (*každé poloze*), now *každé orientaci*
with *polohuje* in its pose row, so it lands on *Baterie jej stále polohuje*. Both
tables keep their link counts' scale (fi 94, cs 102).

**No line-height rule.** Finnish's marks are German's diaereses plus *å*, with nothing
stacked or tall; German needs no `:lang` rule and neither does Finnish.

**No native review pass.** The review sheet carries eleven Finnish questions: *fusee*
