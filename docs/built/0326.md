## §326 — The strap width is adjustable, and 19 mm by default

The owner asked for the strap width to be adjustable and the default changed to 19 mm (2026-11-01). The strap width is the INTERIOR gap
between the lugs' facing walls: the size a strap is bought in and the spring bar's free length. Before this it was a literal in
`main.js` (`CASE_LUG_INNER = 20 / UNIT_MM`), sitting ON the 20 mm owner cap (`CASE_LUG_SPAN_MAX`).

- **`STRAP_MM_DEFAULT = 19`** (`src/layout.js`), the one declaration of the default, above `SPEC` so the spec can read it.
- **`SPEC.strapMm`**, read from `?strap=<mm>` (`index.html`'s roster, so the share link and variants carry it). Any positive finite
  number is kept as asked, like every other station spec: `main.js` warns past the 20 mm cap (the bar cannot be longer than the cap)
  rather than a clamp silently building a different watch than the URL named. A value equal to the default is `null`, so `?strap=19`
  is the default's own `configKey`, not a second spelling of it.
- **`CASE_LUG_INNER = (SPEC.strapMm ?? STRAP_MM_DEFAULT) / UNIT_MM`** (`src/main.js`). Everything downstream already derived from it:
  the lug centres (`+ CASE_LUG_T`), `caseLugPlan` (so each lug's section is re-solved for the strap load at its new offset), the
  schematic tier, and the free case's lug flats (`FITTED_FLAT_MIN`).
- **The cap is not moved.** 20 mm stays the hard ceiling; the default now stands 1 mm under it. `tools/probe-lug-geom.mjs` holds the
  metal to the default (interior measured 19.000 mm) and holds the default under the cap as its own check.
- **Keys the strap must NOT enter.** The alarm arrangement's rows (`ALARM_ARR_KEY`), the gong seat's key (`GONG_SPEC_KEY`) and the
  case selector's seat match name the movement's metal, which the strap does not move, so each nulls `strapMm` as it nulls `hands`.
  Without that a non-default strap lost the arrangement's arming-spring row and warned at boot (found by booting `?strap=17`).
  `FREE_KEY` keeps the strap: the free outline's lug flats follow it, so a non-default strap on the free case has no generated row
  until `tools/free-outline.mjs --spec 'strap=…'` writes one, and says so.

**What moved, because the default did.** The lugs are 1 mm closer, so the free case's lug flats are 0.5 mm shorter each side
(`need` in `src/free-outlines.js`): the three rows regenerated, lands −140° 895.06 → 884.15 mm², alarm off 862.35 → 849.56, default
950.31 → 940.52. The geometry fingerprint does NOT move: booted on the 19 mm default it reads 1995847421, the value it held at 20 mm (measured, not
assumed). The lugs are not in what it hashes, so it is silent about this change either way, and the interior span is held by
`probe-lug-geom.mjs` instead (19.000 mm measured).

**Not done.** `src/gong-seats.js` (the form kinds' seats) was solved at 20 mm lugs. The `fitted` kind's flat reach follows the strap
(`FITTED_FLAT_MIN`), so its seat may want re-solving (`tools/gong-seats.mjs`); whether the other kinds' seats move was not measured.

**Landing 2 — the on-screen control.** A "Strap width (mm)" select sits beside Case shape and Alarm in the running panel
(`#spec-strap`, `src/main.js`) and in the loading screen's Appearance panel (`#boot-strap`, `index.html`). It is reload-tier, like
both: a pick sets `?strap=` and reloads, and the default's option has value `''` so picking it clears the key. Its options are whole
millimetres from 14 (a picker's floor, not a limit) up to the owner cap, both ends read from `layout.js` (`STRAP_MM_DEFAULT`,
`CASE_LUG_SPAN_MAX`), never typed; a URL width off the menu is added so the box never shows a strap the build is not cut for. The label
is a key in all 23 locale tables, written by the model and owed the native review every locale already owes. Booted at the default,
`strap=17` and `strap=17.5`: 0 warnings, and the select reads each.
