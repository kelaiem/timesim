# TODO — mechanical realism backlog

Open work on the movement's mechanical honesty, kept here because it was
previously living only in chat transcripts and a session-local task list.

Most of these came out of a mechanical-engineering realism review that ranked
the movement's gaps by how badly they undermine "could this watch actually be
built". The support-structure findings (items 2, 3, 4, 7 of that review) are
closed — see [Recently closed](docs/todo/recently-closed.md).

**Each item is its own file, `docs/todo/NNNN.md`**, its `## N. Title` heading
first. This file is the index: the table below is GENERATED from those
headings, so it cannot fall behind them. The single file had reached 2.2 MB,
past what the GitHub app opens, and every branch appended to the end of it.
Item numbers are permanent IDs cited as `TODO 117`, never by file or line.

- **To file an item:** claim its number (`node tools/claim-item.mjs
  --namespace TODO --title "…"`), write `docs/todo/NNNN.md` opening on
  `## N. Title`, then run `node tools/item-docs.mjs --write` to refresh this
  index. The Item numbers workflow runs `--check`, so a stale index fails CI.
- **To close one:** edit its file in place, and say so in its heading
  (`— DONE`, `— CLOSED (§n)`), which is what the State column reads.
- **The heading convention:** a bare `## N.` heading is OPEN; closed and
  part-closed items say so in the heading and keep their text, edited in
  place to record what was built.
- **The hand-written status table**, with what remains on each item, is
  [docs/todo/STATUS.md](docs/todo/STATUS.md), along with how to verify a fix
  with the inspector.
